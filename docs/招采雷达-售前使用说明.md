# 招采雷达｜售前使用说明

打开 **hiwork → 技能中心**，搜索并安装 **招采雷达**，然后在对话里提问。说清 **负责的城市、时间范围、业务方向、想要的结果**。

[查看软硬件覆盖方向和提问示例海报](tender-radar-presales.png)

| 我想做什么 | 复制这句话，把城市和业务换成你的 |
|---|---|
| 找辖区商机 | 我负责武汉、黄石。请找近 30 天发布的校园信息化项目，重点看访客预约、人员通行、出入口管理。列出项目、采购人和入选依据。 |
| 找客户和合作伙伴 | 查近三个月河南省发布的生态环境信息化招标项目。按同一批项目分别列出采购人和中标人前 10 名，按项目去重，每家举一个项目，并说明多少项目尚未查到中标人。 |
| 核验采购需求 | 针对公告 ID【填上一步返回的编号】，查正文和附件：采购人是要建设监管平台，还是只要求在已有平台上传报告？请引用原句；找不到依据就标明。 |

**看结果时记住三点：**

- 默认找软件建设、系统集成、升级和运维机会。想连纯设备、工程或检测服务一起看，请明确说“查全部采购”。
- “近三个月发布招标的项目，后来谁中了”和“近三个月公布中标结果，谁中得多”是两种统计。按你真正关心的时间提问。
- “待核实”表示交付依据不足，默认不进排行。公告概要不是原文；重点项目继续追问“给我看原句和公告编号”。结果偏少时，可补充具体能力词，例如把“智慧园区”展开为“车辆预约、访客登记、停车管理”。
